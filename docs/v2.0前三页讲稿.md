# GeoGuessrEX v2.0 前三页讲稿

---

## P1 — 封面

大家好，我们今天的项目是 **GeoGuessrEX**。

一句话概括：**用一组图片，讲述一段故事。**

这是一个基于 Google 街景的地理探索游戏。玩家看到一张街景画面，判断自己在哪，在地图上标记位置。接下来我们展开讲讲怎么玩、怎么算分。

---

## P2 — 基本玩法：图寻挑战

玩法叫"图寻挑战"。核心规则：

系统从已审核的公共题库**随机抽题**，玩家进入全屏街景画面，自由观察建筑、植被、路牌、语言等线索，**没有时间限制**。每局可选 3 题、5 题或 10 题。

提交猜测后，系统展示**双标记地图**——你的猜测位置和正确答案同时显示，中间用虚线连接。同时给出距离和单题得分。整局结束后有**结算面板**：总分、平均距离、最佳单题，还可以和历史成绩对比。成绩会写入个人统计，玩家可以选择分享到社区。

简单说就是：**抽题 → 看街景 → 找线索 → 标位置 → 看结果**，四步一次循环。

---

## P3 — 评分机制：距离如何换算为得分

刚才提到距离和得分，这里展开：核心是两个公式。

第一个，**Haversine 大圆距离公式**。输入玩家猜测的经纬度和正确答案的经纬度，计算球面最短距离，单位千米，地球半径取 6371 公里。

第二个，**指数衰减得分公式**。满分 5000 分。距离越近分越高，猜对位置直接 5000 满分。指数衰减的好处是远端也有区分度——不会说稍微猜远一点就零分了。

代码里就是一行：`5000 × e^(-距离/2000)`。距离 0 公里满分，2000 公里约 1840 分，然后逐渐趋近于零。
