## P5 — 评分机制（一页讲透）

**布局**: 左公式 + 右曲线图

```
┌──────────────────────────┬──────────────────────────────┐
│  ■ 怎么算距离？             │  ■ 得分曲线                    │
│                           │                              │
│  Haversine 大圆公式        │   5000 ┤                      │
│  ─────────────────        │        │ ╲                    │
│  a = sin²(Δlat/2)         │        │   ╲                  │
│    + cos·cos·sin²(Δlng/2) │        │     ╲                │
│  c = 2·atan2(√a, √(1−a)) │   2500 ┤       ╲              │
│  d = 6371 × c             │        │         ╲            │
│                           │        │           ╲          │
│  ■ 怎么算分数？             │      0 ┤             ╲───    │
│  5000 × e^(−d / 2000)     │        ├──────────────────    │
│  满分 5000，距离衰减        │        0    2000   4000  km   │
└──────────────────────────┴──────────────────────────────┘
```

**设计建议**: 右侧用实际数据画一条俯冲曲线，标注几个关键点（0km→5000分，2000km→~1800分，5000km→~400分）。

## 附录：排版技巧建议

| 技巧 | 说明 |
|------|------|
| **统一配色** | 整套 PPT 只用 3 个主色（橙 + 绿 + 米白），不要每页换风格 |
| **留白充足** | 每页文字不超过 5 行正文，用短句不用长段 |
| **代码截图** | 不要贴代码，用高亮截图或简化流程图代替 |
| **动画克制** | 只用淡入和推入两种转场，禁用飞舞动画 |
| **数据可视化** | 评分曲线、架构图、时间轴都用图不用表 |
| **字体统一** | 全篇只用一种中文字体 + 一种英文字体 |
| **页脚统一** | 每页右下角放 `GeoGuesr MVP · 2026.07` |
